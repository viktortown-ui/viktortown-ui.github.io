Файлы для корневого репозитория viktortown-ui.github.io

1) Создай репозиторий с именем: viktortown-ui.github.io
2) Залей туда эти файлы в корень (root)
3) Включи GitHub Pages: Settings → Pages → Deploy from a branch → main / (root)
После этого:
- Яндекс сможет подтвердить права на https://viktortown-ui.github.io/ по HTML-файлу
- robots.txt в корне укажет sitemap на /unitcalc/sitemap.xml
